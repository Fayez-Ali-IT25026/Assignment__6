# 🏋️ FitLog

FitLog is a modern workout library web application that helps users explore workouts, view detailed exercise information, create a personal workout plan, and save workouts for later.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Context API
- React Toastify
- REST API
- LocalStorage

## ✨ Key Features

### 1. 🏋️ Workout Library
Browse a collection of workouts with information about muscle groups, equipment, duration, calories, difficulty, and rating.

### 2. 📋 Personal Workout Plan
Add workouts to Today's Plan and manage up to 5 workouts at a time. Users can view details, mark workouts as done, or remove them.

### 3. ⭐ Save for Later
Save favorite workouts for later and manage them from the Saved section.

### 4. 🔍 Workout Details & Sorting
View detailed workout information, instructions, key specifications, and sort workouts by duration, calories, or rating.

### 5. 📱 Responsive Design & Notifications
The application is responsive across mobile, tablet, and desktop devices and provides toast notifications for important actions such as adding, saving, and removing workouts.
